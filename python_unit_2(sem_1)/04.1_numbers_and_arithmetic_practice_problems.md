python

Explain why the results are different.
### Answer
First expression:
20 - 5 + 2

Addition and subtraction have the same precedence, so calculate from left to right:


20 - 5 = 15
15 + 2 = 17

Result:
17

Second expression:
20 - (5 + 2)

First calculate inside brackets:
5 + 2 = 7

Then:
20 - 7 = 13

Result:
13

The results are different because brackets are calculated first.

## D. Floor Division and Modulus

### 17.
A class has 23 students. If each group contains 5 students:

- How many complete groups can be made?
- How many students will remain?

Use // and %.
### Answer
python
students = 23
group_size = 5

complete_groups = students // group_size
remaining_students = students % group_size

print("Complete Groups:", complete_groups)
print("Remaining Students:", remaining_students)

Output:

Complete Groups: 4
Remaining Students: 3


### 18.
A shop has 47 products. Each box can contain 6 products.

Write a Python program to find:

- Number of complete boxes
- Number of remaining products
### Answer
python
products = 47
box_capacity = 6

complete_boxes = products // box_capacity
remaining_products = products % box_capacity

print("Complete Boxes:", complete_boxes)
print("Remaining Products:", remaining_products)

Output:

Complete Boxes: 7
Remaining Products: 5

### 20.
Write a small Python program that calculates the total cost of 4 products when each product costs ₹75. Then calculate how many complete groups of ₹100 can be made from the total using floor division, and what amount remains using modulus.
### Answer
python
product_quantity = 4
product_price = 75

total_cost = product_quantity * product_price

complete_groups = total_cost // 100
remaining_amount = total_cost % 100

print("Total Cost:", total_cost)
print("Complete Groups of ₹100:", complete_groups)
print("Remaining Amount:", remaining_amount)

Output:

Total Cost: 300
Complete Groups of ₹100: 3
Remaining Amount: 0
